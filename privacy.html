This Privacy Policy explains how CocAttackReview accesses, uses, stores, and deletes information when using YouTube API Services.

1. Scope and users

CocAttackReview is a personal desktop tool used only by its developer. It is not offered to third-party users and does not provide public account registration or login.

2. Use of YouTube API Services

CocAttackReview uses YouTube API Services. The tool uses Google OAuth authorization to access the developer's own YouTube channel for video publishing operations.

Google's privacy practices are described in the Google Privacy Policy.

3. Information accessed and stored

The tool may access or store information necessary to operate the publishing workflow, including:

  • the authenticated YouTube channel identifier;
  • the designated playlist identifier;
  • uploaded YouTube video identifiers;
  • publishing and scheduling status returned by the YouTube API;
  • OAuth authorization tokens; and
  • resumable-upload session information while an upload is in progress.

The tool does not request, collect, or store the user's Google or YouTube password. It does not use YouTube API data for advertising, profiling, or sale.

4. How information is used

Information is used only to authenticate the developer, verify the intended YouTube channel, upload the developer's own videos and thumbnails, add videos to the intended playlist, schedule publication, verify API results, and safely resume interrupted uploads.

5. Storage and security

Data used by CocAttackReview is stored locally on the developer's Windows computer. OAuth refresh tokens and resumable-upload session information are protected using Windows user-level encryption. Credentials are not intentionally stored in the source code repository.

6. Sharing

CocAttackReview does not sell YouTube API data and does not share it with advertisers or unrelated third parties. Data is transmitted to Google/YouTube only as required to perform the requested YouTube API operations.

7. Cookies and tracking

This informational website does not intentionally use advertising trackers or analytics. The CocAttackReview desktop tool does not use browser cookies for its own tracking purposes.

8. Revoking access

Google account access granted to CocAttackReview can be revoked from Google Account security settings.

After authorization is revoked, locally stored Authorized Data associated with that authorization will be deleted as soon as reasonably possible and no later than 7 calendar days after revocation is identified.

9. Data deletion requests

Because CocAttackReview has only one user (the developer), the developer can remove the tool's locally stored state and credentials directly. A deletion request may also be sent to REPLACE_WITH_CONTACT_EMAIL.

Deleting CocAttackReview's locally stored data does not delete content stored by YouTube. YouTube-hosted content must be deleted through YouTube or an authorized client that supports that operation.

10. Changes

This policy may be updated if the tool's use of YouTube API Services changes. Material changes will be reflected on this page before the new use is introduced.
