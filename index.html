About

CocAttackReview is a private, locally operated desktop tool used by its developer to prepare, upload, and schedule Clash of Clans gameplay review videos on the developer's own YouTube channel.

The tool is not offered as a public service and is not available to third-party users. It is used only by the developer on the developer's own Windows computer.

YouTube API usage

CocAttackReview uses YouTube API Services for the following limited purposes:

  • uploading the developer's own videos;
  • uploading thumbnails;
  • adding uploaded videos to a designated playlist;
  • reading the authenticated channel and publishing state needed for verification; and
  • scheduling publication of the developer's own uploaded videos.

OAuth authorization is performed by the developer in a web browser. The tool does not ask for, collect, or store the developer's Google or YouTube password.

Data handling

OAuth credentials and workflow state are stored locally on the developer's computer. Refresh tokens and resumable-upload session information are protected using Windows user-level encryption. The tool does not sell API data, use it for advertising, or provide it to third parties.
